# Library Management System (BCA Final Year)

A simple desktop project made with Python Tkinter and SQLite.

## Features
- Add, update, delete and search books
- Track total and available copies
- Issue books to students
- Return books and automatically update available quantity
- View issue history and status

## Requirements
- Python 3.8 or newer
- Tkinter (included with most Python installations)
- No third-party packages required

## Run
1. Extract the ZIP.
2. Open a terminal in this folder.
3. Run: `python main.py`
4. `library.db` will be created automatically.

## Files
- `main.py` — application source code
- `project_report.md` — editable report template
- `sample_books.csv` — sample book details to enter manually
